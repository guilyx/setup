How To Use

  • Local laptop: fill Dev + Dotfiles, click Generate, then Run Local Dev Setup.
  • VPS: set inventory path, deploy user, SSH keys, and domain/upstream; then run generated VPS command.
  • SSH keys: paste one public key per line in the VPS section. Keys are installed for the deploy user.
  • Safer rollout: run generated `vps_check_command` first, then apply.
